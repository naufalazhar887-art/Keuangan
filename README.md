# Catatan Keuangan Bulanan

Web sederhana untuk mencatat pemasukan, pengeluaran, dan tabungan, lengkap dengan saldo bersih dan rekap sebulan.

## Fitur
- Pemasukan, pengeluaran, tabungan, dan saldo bersih
- Rekap per kategori, per hari, dan per minggu
- Kategori bisa dibuat sendiri
- Format rupiah otomatis (Rp 100.000)
- 10 tema warna dan efek suara (bisa dimatikan)
- Data tersimpan otomatis di browser (localStorage)

## Cara pakai
Buka `index.html` di browser. Tidak perlu install apa pun.

## Cara online lewat GitHub Pages
1. Upload `index.html` dan `README.md` ke repository GitHub.
2. Buka **Settings** > **Pages**.
3. Di **Build and deployment**, pilih **Deploy from a branch**, lalu pilih branch `main` dan folder `/ (root)`.
4. Simpan. Beberapa menit kemudian web bisa dibuka di `https://USERNAME.github.io/NAMA-REPO/`.

## Catatan
Data tersimpan di browser yang dipakai, jadi tidak ikut pindah ke perangkat lain.
